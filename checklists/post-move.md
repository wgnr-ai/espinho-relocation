# Post-Move Checklist (First 30 days)

## Registration & Legal
- [ ] Register at concelho (municipal registry)
- [ ] Begin Cartão de Cidadão renewal if needed
- [ ] Exchange driving license or obtain IDP
- [ ] Register with local tax authority

## Healthcare
- [ ] Enroll in SNS (Serviço Nacional de Saúde)
- [ ] Request family doctor assignment
- [ ] Transfer prescriptions to local pharmacy
- [ ] Activate private health insurance if chosen

## Banking & Finance
- [ ] Open PT bank account if not done pre-move
- [ ] Set up MB WAY (mobile payments)
- [ ] Transfer funds from US accounts
- [ ] Notify US banks of new address

## Utilities & Services
- [ ] Set up EDP (electricity)
- [ ] Set up water service
- [ ] Activate internet/TV (NOS, MEO, or Vodafone)
- [ ] Get PT mobile phone plan

## Daily Life
- [ ] Explore local grocery stores and markets
- [ ] Learn public transit routes (train, bus)
- [ ] Find community groups and activities
- [ ] Help Leo settle into routine
