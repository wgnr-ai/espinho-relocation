# Documentation Hub

## Purpose
Central documentation for the 8 relocation workstreams. Each subdirectory is a distinct research and planning domain.

## Ownership
Project-level; each workstream is independently researchable.

## Local Contracts
- housing/ — finding housing in Espinho and surrounding areas
- healthcare/ — SNS registration, private insurance, specialist availability
- finance-taxes/ — banking, NIF, US-PT tax treaty, cost of living
- legal-documents/ — Cartão de Cidadão, driving license, vital records
- shipping-logistics/ — international movers, customs, bring-vs-buy
- leos-care/ — elder care services, accessibility, support network
- daily-life/ — transit, utilities, grocery, community, language
- timeline/ — month-by-month countdown to January 2027

## Work Guidance
- Each workstream README follows a consistent template: Overview, Research Questions, Key Findings, Action Items, Resources
- Populate Key Findings during research phase
- Date-stamp all findings
- Cross-reference between workstreams when topics overlap
